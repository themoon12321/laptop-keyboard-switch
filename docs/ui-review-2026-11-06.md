# 鼠标选择代替键与坏键（2026-11-06）

坏键不能可靠按出来，因此规则编辑的两处键名输入框改为按钮。点击“代替键”或“坏键”打开同一套完整键盘示意，鼠标选择键帽、确认后更新编辑草稿；无需按下真实按键，也不发送模拟按键。主页面布局和视觉样式保持不变。

键盘包含字母、数字、符号、F1–F12、编辑导航区、方向键、数字小键盘及音量键；暂不支持的修饰键、锁定键、Fn 等置灰。当前键预选；点键帽只预览，取消不改变原值，确认才回填，保存规则后才应用。弹窗关闭后恢复父窗口操作，关闭编辑器也关闭关联的选键弹窗。

编辑器直接持有扫描码，避免通过展示名称重新解析导致上排数字、小键盘或标点键混淆。界面说明 `/` 与 `?` 共用一个物理键位，实际字符仍随 Shift、NumLock 和键盘布局解释。

验证：选键测试 17 项、原手势/编辑测试 29 项、隔离集成 19 项断言及 CLI 检查通过；主程序和打包后的程序语法/依赖校验通过。实际绘制并检查了完整键盘和规则编辑窗口。测试不操作真实键盘驱动，不改动本机生效规则。README 的个人实验及未验证其他机器声明继续保留。
