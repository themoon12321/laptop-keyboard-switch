# 2026-10-28 复用、安装与卸载改造

目标是让其他电脑按自身设备安装，并可按安装前记录撤销本工具改动。原脚本在安装驱动之后才备份过滤器，无法恢复真正的安装前状态；卸载无条件删除固定入口、共享驱动及过滤器。新版本先保存机器/用户记录，再执行变更。

## 改动

- `InstallState.psm1`：按机器和安装路径保存快照、区分不存在和空属性、原子更新 JSON、只恢复拥有的差异，保留后加的第三方过滤器。
- `MachineInstall.ps1`：仅机器层提权，按本机 PnP 实例绑定新驱动；复用已有服务时不改服务/过滤器。部分失败保留前像，重复安装不覆盖前像。共享副本和未知绑定阻止驱动删除。维护互斥锁避免并发操作驱动。
- 用户安装记录原始自启项和快捷方式；升级保留现有规则；卸载遇到别的程序改动则停止，删除进程按脚本完整路径核实。
- 新用户的默认配置与本机运行配置分离，新机器默认直通、替代关闭。首次识别、新片段均需确认；同句柄多个设备拒绝歧义选择。修复重新识别函数遗漏 `iniFile` 全局声明，识别观察订阅纳入统一释放记录。
- 新增只读诊断、启动入口、卸载入口、重启后卸载验证、有限范围记录清理、白名单 ZIP 打包与 SHA-256 清单。
- 本机历史修复脚本与运行配置仅从 Git 索引移除，原文件仍留本机；旧提交和初始备份标签保留。分发 ZIP 不包含它们。
- 补充安装/恢复/旧版迁移/共享驱动说明、第三方来源与随附许可。自有代码开源许可由仓库所有者决定。
