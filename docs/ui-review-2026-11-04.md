# 本地交互打磨（2026-11-04）

README 首部已明确声明：当前仅有个人电脑使用/复现和隔离软件测试，未在其他实体机或生产环境完成完整验收，不建议自行安装部署。兼容性验证暂缓，本轮只打磨本地交互。

## 行为变化

- 主面板改为浅色分区：输入状态、切换快捷键、按键替代、暂停时保留的按键。使用统一字号、留白和状态颜色，去掉状态后的设备数量及底层术语。
- 规则编辑去掉个人三条规则的恢复入口。选中后直接改时间、按键和模式，保存自动包含当前编辑，不必先更新。时间标明毫秒并显示秒数，错误和未保存状态在窗口内说明。改变源键替换当前规则，避免额外生成旧规则；取消不改变已生效配置。
- 快捷键录制在主面板显示倒计时、修饰键按下过程、完整组合和待保存状态。松开后需明确保存；取消、Esc、超时、失焦或关闭面板结束录制，保留原快捷键。
- 录制期间释放本工具的输入处理并暂停旧切换键，结束后恢复用户原有目标状态。旧录制器的异步结束事件不能取消新录制器；注册或持久化失败会尝试撤销新注册、保留原设置。
- 录制开始前要求松开修饰键，避免吞掉进入录制之前已按下的修饰键抬起事件。内置键盘暂停时的恢复组合接受左右两侧的同类修饰键。
- “豁免”改为“暂停时保留的按键”；“紧急恢复”改为“输入异常？停止处理并退出”，明确动作是停止本项目处理并退出程序。

- 应用及白名单打包后的应用通过 AHK `/validate`。
- 核心仿真 33 项通过；手势及规则编辑测试 29 项通过；快捷键录制状态测试 10 项通过。
- 隔离集成 19 项断言及 CLI/单实例检查通过，包括实时预览、明确保存、取消/失焦恢复、旧事件隔离、注册失败回退和面板边界。
- 主面板、录制状态、替代规则编辑器以测试窗口在桌面外、不抢焦点地绘制，检查实际渲染。测试使用假 AHI、假录制器、假快捷键注册，不发送实际输入，不更改真实驱动或用户规则。

录制器的真实按键体验仍需本机人工检查；上述仿真不等于其他机器的驱动或兼容性验证。

## 本机人工检查

从托盘退出旧程序，再运行 `start.cmd`，已有规则和时间不覆盖。

1. 进入录制，依次按修饰键与主键，看面板预览；松开后应显示待保存，旧快捷键仍有效；点击保存才替换。
2. 分别尝试 Esc、取消、切走窗口，确认原快捷键和录制前的内置输入状态恢复。
3. 修改一条规则的时间并直接保存，重新打开设置确认持久保留；修改后取消则保留旧值。
4. 暂停内置输入时用左右修饰键分别组成切换组合，确认均能恢复。
