# 内置键盘开关与坏键替代

外接键盘叠放在笔记本上时，可以屏蔽内置键盘，避免误触；使用内置键盘时，可以用长按或双击其他键来替代坏键。

基于 AutoHotkey v2 和 Interception。输入处理只订阅已确认的内置设备，外接键盘不应用替代规则。驱动本身的绑定范围和硬件兼容性仍需单独验证。

## 本机先注意这件事

2026-10-25 的排障记录显示，为解决“外接键盘可连接、音量键可用、主输入区失效”，已从键盘类 UpperFilters 移除 `keyboard`，并将它写入内置 PS/2 键盘的设备级 UpperFilters。当时设备重启返回 50，并提示等待系统重启。

2026-10-26 复查时，注册表仍是上述配置，系统最后开机时间为 2026-10-19。因此，**设备级配置的冷启动效果尚未验证**。本次开发没有修改实际驱动、设备、电源策略或自启动，也没有自动重启电脑。

`setup.ps1` 现在检测并保留已有的设备级绑定，避免重装时重新挂回所有键盘。新机器的官方安装器仍使用类级过滤；不能把本机的排障结果当成所有蓝牙/2.4G 设备都兼容的保证。

## 日常使用

- 双击桌面「键盘开关」，或双击托盘图标打开面板。
- `Ctrl+Alt+K` 切换截断/恢复内置键盘，可以在设置中修改。
- 内置键盘被截断时，仍可用左侧修饰键组成的紧急组合恢复。
- 面板/托盘 → **坏键替代设置（长按 / 双击）…**：启停、添加、更新、删除规则或恢复默认规则。
- 面板/托盘 → **紧急恢复键盘**：尝试释放本工具订阅、清除修饰键，并退出。
- 托盘黄图标表示尚未识别或释放状态未确认；发生错误时查看 `app/KeyboardToggle.log`。

## 你的坏键默认规则

默认已配置并启用，重新打开程序后生效；仅用于内置键盘。

| 操作 | 输入结果 |
| --- | --- |
| 长按 X 约 600 毫秒 | Z 对应的键位；大小写由 Shift/CapsLock 决定 |
| 长按句号 / > 共用键约 600 毫秒 | `/`；按住 Shift 时为 `?` |
| 长按上排数字 3 满 3000 毫秒 | 上排数字 4；按住 Shift 时为 `$` |
| 短按这些键 | 原来的 X、句号或数字 3 |

长按到阈值时输出一次目标键，不额外输出原键，也不连续输出目标键。快速连续输入其他键会提前放行原键，保持打字顺序。Ctrl/Alt/Win 快捷键优先保留原键，例如 Ctrl+X 仍然是剪切。

设置中支持 **长按** 和 **双击**，时间范围 150–10000 毫秒。双击模式下，单击需等待双击窗口结束，或者遇到下一个按键时提前放行；这是区分单击和双击所需的延迟。暂不支持把修饰键、锁定键或 Fn 当作规则源键/目标键；普通 F1–F12 可以作为目标键。

Fn 通常由笔记本固件处理，本项目不承诺模拟 Fn 或切换固件的功能键模式。如只需 F1–F12，可配置其他键长按输出对应 F 键。实际字符仍由当前键盘布局和输入法解释。

配置保存在 `app/KeyGestures.ini`，与设备缓存和开关状态分开。保存后实时应用。内置键盘被截断时替代功能暂停；扫描豁免时临时恢复普通输入，结束扫描后自动恢复替代功能。需要完全直通时关闭“坏键替代”并恢复内置键盘。

## 安装和卸载

Windows x64/x86 专用；ARM64 不支持。Interception 是内核驱动，安装需管理员权限及重启，其兼容性受 Windows 安全设置和厂商驱动影响。
检测到内存完整性（HVCI）启用时，安装器会停止；无人值守参数也不会跳过该检查，脚本不会更改 Windows 安全设置。

- 新机器：运行 `setup.cmd`，读完预检提示再安装，安装后重启。
- 本机已有设备级绑定：`setup.ps1` 会保留绑定并跳过官方驱动重装；无需为本次功能开发重新安装。
- 仅用户组件：`install.ps1` 创建桌面入口和当前用户自启动。
- 保留驱动卸载：`uninstall.ps1`，先请求当前安装释放，再按完整脚本路径结束残留进程。
- 完全卸载：`uninstall-all.ps1`，先清除设备级绑定，再卸载驱动、清理类过滤器；失败时查日志，完成后重启。坏键规则配置默认保留。

命令行：

```powershell
$ahk = 'app\AutoHotkey\AutoHotkey64.exe'
$script = 'app\KeyboardToggle.ahk'
& $ahk $script gui
& $ahk $script status   # 无守护时仅报告未运行
& $ahk $script release  # 释放本安装并退出
```

## 可靠性与边界

- 按设备整键盘订阅；订阅前及收到输入时核对设备编号、句柄、设备类型。
- 保存“用户期望状态”和“当前实际处理状态”，设备改号或暂时消失不再把截断意图覆盖成允许输入。
- 取消订阅失败会保留所有权记录，显示未确认状态，并阻止带着旧订阅重新开启过滤。
- 命名互斥锁防重复启动；PID 转发前核实脚本完整路径。
- `SetState(false)` 只作用于当前 AHI 上下文；它不能修复其他进程或任意驱动故障。`SubscribeKeyboard` 内部也会开启过滤，不能仅凭省略显式 `SetState(true)` 就宣称外接键盘绝不受影响。
- 开启坏键替代时，内置键盘的普通输入也经过回调并重新发送，以保证原键与后续按键的顺序。出现输出错误会暂停处理并尝试放行；仍需真机验证输入法、多媒体键、睡眠唤醒和设备重连。
- 多用户、多个项目副本或其他 Interception 工具同时运行，仍可能争用驱动；本项目的互斥锁只覆盖当前安装及当前会话。
- `_devfilter.ps1`、`_unfilt2.ps1` 是本机历史排障实验，包含固定设备路径，不作为日常安装入口。
